# Phoenix Documentation

## Purpose

This directory contains the governance, architecture, and engineering knowledge of the Phoenix Framework.

The Constitution is the highest authority. Every architectural decision, engineering standard, and implementation work order derives from it.

---

## Documentation Structure

### constitution/

The governing document of the Phoenix Framework.

Defines:
- Purpose
- Vision
- Articles
- Governance
- Architectural authority

---

### articles/

Constitutional articles expanding the Constitution.

---

### principles/

Enduring architectural principles.

Naming convention:

PR-000001.md

Example:

PR-000001 — Kernel Stability

---

### standards/

Engineering standards.

Naming convention:

PS-000001.md

Example:

PS-000001 — Self-Describing Artifacts

---

### adr/

Architecture Decision Records.

Naming convention:

ADR-000001.md

Each ADR documents:

- Context
- Decision
- Consequences

---

### work-orders/

Implementation planning.

Naming convention:

WO-000001.md

Each Work Order defines:

- Scope
- Deliverables
- Acceptance Criteria
- Milestones

---

### architecture/

Architecture diagrams, dependency models, subsystem documentation, and design references.

---

### glossary/

Shared terminology used throughout Phoenix.
